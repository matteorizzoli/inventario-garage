# Apps Script (Fase 3 — non ancora implementato)

Questa cartella conterrà il codice della web app Google Apps Script legata al
Google Sheet (SPEC §6): `doPost` con le azioni `pull`, `push`, `upload`, `file`
e verifica del token su ogni chiamata.

Il codice andrà incollato e pubblicato a mano nell'editor di Google. URL della
web app e token **non** vanno mai scritti nel repository: l'app li chiede al
primo avvio e li salva solo sul dispositivo.
